## Project Name
Home Automation via Bluettoth

## Project Scope
This project aims to develop a Bluetooth-based home automation system using Arduino Uno and the HC-05 Bluetooth module. It enables users to wirelessly control hpusehold appliances through a smartphone,providing a simple and low-cost automation solution.


## Project Description
The Home Automation via Bluetooth project uses an Arduino Uno and an HC-05 Bluetooth module to establish wireless communication between a smartphone and electronic devices. Commands sent from a Bluetooth terminal application are processed by the Arduino to control connected appliances represented by LEDs. This project demonstrates the concepts of embedded systems and wireless home automation.
